# ICICI BANK Developer Console

A modern web-based developer console for generating HMAC signing keys and managing API authentication.

## Features

- Secure HMAC key generation
- Master and Account-linked key modes
- Payment verification workflow
- Manual payment history
- Activation countdown
- Responsive user interface
- Pure HTML, CSS, and JavaScript
- No backend required

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/ayekarinfotech/hmacicici.git
```

2. Open the project folder.

3. Launch `index.html` in your browser.

## Deployment

This project is hosted using **GitHub Pages** with a custom domain.
